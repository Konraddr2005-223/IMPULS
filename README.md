# Sąsiedzki

**Pomysł z okolicy. Wspólne działanie.**

Responsywna PWA pomagająca mieszkańcom Krakowa rozwijać pomysły okolicy: mapa → sprawdzenie terenu → poparcie sąsiadów → roboczy wniosek BO.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Leaflet (kolejne kroki)
- Supabase, OpenAI API (kolejne kroki)

## Rozwój

```bash
npm install
npm run dev
npm test
npm run build
```
