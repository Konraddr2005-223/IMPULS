# Prezentacja Sąsiedzki — 10 slajdów (§10)

1. **Problem** — Od pomysłu do formularza BO jest daleko (teren, treść, pierwsze poparcie).
2. **Hipoteza** — Sąsiedzi chcą najpierw sprawdzić teren i zebrać sygnał zainteresowania, zanim wypełnią oficjalny formularz.
3. **Rozwiązanie** — Mapa → teren → lajki/komentarze → roboczy wniosek (AI + katalog kosztów) → złożenie w systemie miasta.
4. **Demo flow** — Zielony zakątek (2/3 → trzeci lajk → generator).
5. **Teren** — presentation-A (inny podmiot) vs presentation-B (gminny); tryby live/cache/demo.
6. **Poparcie vs podpisy** — Lajk ≠ podpis BO; instrukcja list poparcia.
7. **Koszty** — 2 ławki + 4 drzewa → 9 795–16 700 zł z cennika (nie z AI).
8. **Usterki** — poza sezonem BO; status społecznościowy.
9. **Stack i limity** — PWA, Supabase, adapter Krakowa; ujawnienie AI.
10. **Następne kroki** — SMTP, Web Push, pełny MSIP, hosting Cloudflare Pages.
